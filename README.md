# 四级成绩分析 · CET-4 Score Analyzer

一个面向手机 / 平板的**大学英语四级（CET-4）成绩录入、赋分估算与针对性分析**网页工具。
纯前端、单文件、零依赖、零后端，数据只保存在本机浏览器。

线上地址：**https://zhouks-byte.github.io/cet4-score-analysis/**

---

## 功能

### 1. 按官方试卷结构赋分
参照《英语考试应试指南》第一章「试卷结构」与官方分值比例：

| 部分 | 题型 | 题量 | 分值比例 | 710 分制满分 |
| --- | --- | --- | --- | --- |
| 写作 | 短文写作 | 1 | 15% | 106.5 |
| 听力理解 | 短篇新闻 | 7 | 7% | 49.7 |
| 听力理解 | 长对话 | 8 | 8% | 56.8 |
| 听力理解 | 听力篇章 | 10 | 20% | 142 |
| 阅读理解 | 词汇理解（选词填空） | 10 | 5% | 35.5 |
| 阅读理解 | 长篇阅读（段落匹配） | 10 | 10% | 71 |
| 阅读理解 | 仔细阅读 | 10 | 20% | 142 |
| 翻译 | 汉译英段落翻译 | 1 | 15% | 106.5 |
| **合计** | | **57** | **100%** | **710** |

赋分模型：
- 客观题按「答对题数 × 每题分值比例」得到原始分；
- 写作 / 翻译按官方五档总体印象评分（14/11/8/5/2 分档）以 15 分制自评；
- 加权为百分制原始分后 **× 7.1** 得到 710 分制报道分；
- 额外给出**常模百分位**（常模均值 500、标准差 70 的正态近似）；
- 落实官方规则：**总分 ≤ 220 分记为 0 分、不发放成绩报告单；425 分及以上视为达到「基本目标」**。

支持两种录入方式：**按答对题数**（推荐，自动算分）与**按已知报道分**。

### 2. 便于录入
- 每种题型一个步进器（−/+ 大按钮）+ 数字输入框，可快速点击；
- 写作 / 翻译用滑杆 + 常用档位快捷芯片（0/5/8/11/14 分）；
- 底部「实时估分」条即时反馈总分、各部分得分、距目标差距；
- 越界输入自动修正（如新闻最多 7 题、写作最高 15 分）并提示；
- 录入时间与备注可自定义，方便区分「真题第 N 套 / 某次模考」。

### 3. 多形式可视化
- **折线图**：总分趋势（含目标线与 425 参考线）、分项趋势（四条线可单独开关）；
- **堆叠柱状图**：每次考试的分数构成（写作 / 听力 / 阅读 / 翻译）；
- **水平条形图**：各部分得分、各部分得分率；
- **环形进度图**：最新估分占 710 的比例；
- 全部图表为手写 SVG，支持触摸查看数据提示（tooltip），随容器宽度自适应重绘。

### 4. 针对性分析与建议
- **综合诊断**：分数段评价 + 一句话结论；
- **关键发现**：距目标还差多少分、220 分 0 分风险、最短板板块、单位收益最高的题型、主观题档位差距、客观题失分占比、成绩趋势与波动；
- **提分路径**：按「每题收益 ÷ 当前正确率」贪心求解，告诉你「再多对几道哪个题」可以覆盖目标差距；
- **题型明细**：每个题型的正确率、失分，并附考点说明与提分方法（来自应试指南的实质内容）；
- **学习计划**：按距考试时间（10 周以上 / 5~9 周 / 2~4 周 / 考前周）给出四板块计划模板；
- **报告复制**：一键复制纯文本报告，便于发给老师或同学。

### 5. 界面与交互（v2）
- **响应式双栏**：≥760px 自动切换双栏（趋势/构成 ｜ 得分/贡献/记录），手机端单列；录入页在宽屏变为「左录入 + 右吸顶预览」；
- **仪表盘**：最新估分用 270° 分段仪表盘呈现（0–220 / 220–425 / 425–550 / 550–710 四段语义色），一眼看出所处区间；
- **图表全面升级**：Y 轴改用**整数刻度**（0/150/300/450/600/710），曲线精确穿过数据点，堆叠柱仅顶段圆角，新增环形占比图与图例；
- **交互反馈**：步进器到边界自动禁用、实时估分局部更新（数字弹跳而不整块闪烁）、切页错峰入场动画、图表入场动画只在首次播放（拖动窗口不重播）、Toast 带状态图标；
- 移动优先：320 / 360 / 390 / 430px 均无横向溢出，底部胶囊导航 + 安全区适配；
- 自动跟随系统**深色模式**（浅色/深色均已逐屏验证），支持打印样式；
- 数据持久化到 `localStorage`，支持导出 / 导入 JSON 备份、删除单条、清空全部；
- 无网络请求、无第三方脚本、无统计埋点。

### 6. 图标与按钮布局（v3）
- **站点图标**：`assets/icon.svg`（1:1 正方形），蓝紫渐变圆角底 + 270° 仪表环 + 环心粗体「4」，
  与站内估分仪表盘同构；环心数字经**实测再居中**（包围盒中心对齐画布中心 256,256）；
- **多尺寸输出**：`tools/gen-icons.mjs` 用无头浏览器精确渲染 16/32/48/64/128/180/192/512 PNG，
  并生成 `favicon.svg`、`apple-touch-icon.png`、`manifest.webmanifest`（支持安装到桌面）；
  16px 下仍可辨识；
- **按钮不再遮挡**：新增 `qa/overlap.mjs` 遮挡检测器（5 种视口 × 4 个页面），修复了
  表单双列里 `datetime-local` 撑破列导致压住备注框（改用 `minmax(0,1fr)` + `.input{min-width:0}`）、
  底部导航按钮间隙过小、分段控件选项间距过窄等问题；
- **预览条不再压按钮**：手机端预览条改为固定悬浮，并由 JS 实测其高度写入 `--preview-h`，
  动态预留底部空间，滚到底时「清空重填 / 保存并分析」始终可点；
- 检测结果：**重叠 0 / 不可点击 0 / 溢出 0 / 间隙过近 0**（5 视口 × 4 视图全部通过）。

├── dist/

## 本地开发

```bash
# 构建单文件
node tools/build.mjs

# 单元测试
node tests/model.test.js
node tests/charts.test.js

# 浏览器端自动化 QA（需本机有 Edge 或 Chrome）
node qa/cdp.mjs "file:///<绝对路径>/dist/index.html" qa/out

# 按钮遮挡检测（防回归）
node qa/overlap.mjs "file:///<绝对路径>/dist/index.html" qa/overlap

# 重新生成图标（改了 icon.svg 之后）
node tools/gen-icons.mjs
node tools/wire-icons.mjs
node tools/build.mjs
```

> 注意：`tools/build.mjs` 会强制去掉 UTF-8 BOM —— 带 BOM 的单文件 HTML 会让浏览器提前结束解析，整页退化为纯文本。

## 部署
